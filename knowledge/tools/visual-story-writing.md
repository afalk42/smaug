An interactive text editor that revolutionizes narrative writing by providing visual representations of story elements. This research project demonstrates how visual manipulations can directly suggest text edits, supporting writers in planning high-level revisions and exploring story variations.

## Key Features

- **Entity Interaction Graph** - Visualize and manipulate character relationships; connecting characters in the graph suggests narrative edits
- **Location Timeline** - Track character movement between locations with visual positioning that updates story text
- **Event Timeline** - Chronological visualization of story events that can be reordered to reorganize narrative structure
- **Real-time Text Suggestions** - Visual changes generate suggested text edits for seamless editing
- **Interactive Canvas** - Direct manipulation interface built with TypeScript, React, and Vite
- **GPT-4o Integration** - Leverages advanced AI for extracting story information and generating edits

## Technical Stack

- **Frontend:** TypeScript, React, Vite
- **AI Integration:** OpenAI API (GPT-4o)
- **Design:** Interactive visualization, direct manipulation paradigm

## Why Bookmarked

This represents a significant advancement in writing tools by bridging visual and textual representation. Rather than traditional word processors, it shows how visualization can make narrative structure explicit and editable, encouraging creative exploration through visual feedback.

## Research Context

Based on user studies showing that visual representations support:
- Planning high-level revisions
- Tracking story elements (characters, locations, events)
- Exploring story variations in creative ways
- Understanding narrative structure
