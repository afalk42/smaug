# Grok System Prompts Repository

Public repository containing the system prompts used by xAI's Grok AI assistant and related products.

## Overview

Following a security incident where unauthorized modifications were made to Grok's prompt, xAI decided to publish their system prompts openly on GitHub. This transparency initiative allows the public to review prompts and provide feedback on changes.

## Key Prompts

- **Grok 4 System Prompt** (`grok4_system_turn_prompt_v8.j2`) - Chat assistant on grok.com and X
- **Grok 3 System Prompt** (`grok3_official0330_p1.j2`) - Previous generation chat assistant
- **Grok Analyze Button** (`grok_analyze_button.j2`) - "Grok Explain" feature on X
- **Ask Grok Bot** (`ask_grok_system_prompt.j2`) - Grok bot on X
- **Safety Prompts** - Various safety injected prompts for API models (grok-code-fast-1, grok-4-fast, grok-4-0709)
- **Grok 4.1 Prompts** - Non-thinking and thinking variants with/without tool support

## Significance

This represents a significant step in AI transparency, allowing:
- Public review of AI system behavior
- Community feedback on prompt changes
- Verification of system integrity
- Trust building with users
