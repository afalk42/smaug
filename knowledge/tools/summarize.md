CLI tool and Chrome Side Panel extension by Peter Steinberger for generating fast, clean summaries from URLs, files, YouTube videos, podcasts, and other media. Provider-agnostic with support for local, paid, and free AI models.

## Key Features

- Summarize URLs, PDFs, images, audio/video, YouTube, and podcasts from the CLI
- Chrome Side Panel (and Firefox Sidebar) for one-click tab summaries
- Transcript-first media flow: uses published transcripts, falls back to Whisper
- Provider-agnostic: works with OpenAI, Anthropic, local endpoints, and free OpenRouter models
- Streaming output with Markdown rendering and metrics
- v0.11: Groq for faster TTS, Cursor free tokens support, YouTube slide extraction with OCR
