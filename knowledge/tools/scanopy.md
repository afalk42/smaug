Scanopy is a network diagram generation tool that automatically discovers hosts, services, and their relationships to create clean, up-to-date network documentation with zero ongoing manual maintenance.

## Key Features

- **Automatic Network Discovery**: Scans networks to identify hosts, services, and dependencies
- **200+ Service Definitions**: Auto-detects databases, web servers, containers, monitoring tools, and enterprise applications
- **Interactive Topology Visualization**: Generates interactive network diagrams with extensive customization
- **Distributed Scanning**: Deploy daemons across network segments to map complex topologies
- **Docker Integration**: Automatically discovers containerized services
- **Scheduled Discovery**: Automated scanning keeps documentation current
- **Multi-user Support**: Organization management with role-based permissions

## Use Cases

- Home lab infrastructure documentation
- Network inventory for IT professionals
- Multi-VLAN environment visualization
- Container and microservice mapping
- MSP multi-client network management
