# Ariana - Get More Quality Work Out of Claude Code

Ariana is a platform designed for power users of AI coding agents. It provides capabilities to launch, manage, and share sessions with coding agents across web, mobile, and desktop platforms.

## Key Features

- **Multi-agent orchestration**: Manage multiple AI coding agents simultaneously
- **VPS-based deployment**: Spin up virtual machines and Linux servers in seconds
- **SSH terminals**: Direct access to agent environments
- **Collaborative coding**: Share sessions and work with teams
- **Cross-platform IDE**: Web, mobile, and desktop support
- **Claude integration**: Built specifically for Claude Code and Claude integration

## Use Cases

Ariana enables developers to run AI agents that can perform deeper work on cloud infrastructure, spawning thousands of virtual machines in seconds for parallel processing and advanced agent automation.

The platform is particularly useful for running parallel AI coding tasks at scale, leveraging cloud infrastructure for agent orchestration.
