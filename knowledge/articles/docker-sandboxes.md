Docker Sandboxes provide secure, isolated microVM-based environments for running coding agents like Claude Code, Gemini, and Codex safely without risking the host system. These sandboxes allow agents to install packages, run Docker, and modify configurations in complete isolation.

## Key Takeaways

- Docker Sandboxes use microVM-based isolation for agent execution
- Agents can freely install packages, run Docker, and modify configs without affecting the host
- Supports multiple AI coding agents including Claude Code, Gemini, and Codex
- Enables unsupervised agent execution with built-in safety guarantees
